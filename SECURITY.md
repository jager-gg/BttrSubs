# Security

Please report a vulnerability privately: open [a security advisory](https://github.com/jager-gg/BttrSubs/security/advisories/new) (Security tab, "Report a vulnerability"), not an issue. You'll get an answer within a few days.

Fixes go into the latest 1.x release. Install URLs carry each person's settings and keys encrypted with the server's `CONFIG_SECRET`; anything that could read them, reach a private network through the server, or get past the dashboard's sign-in counts as a vulnerability.
